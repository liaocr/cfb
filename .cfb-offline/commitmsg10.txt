feat(ruler): gen-ruler/5 —— 修掉退化阶梯实测出的两个缺陷（顺序盲 + 奖励删内容）

v4 的软分有两个洞，是拿 60 条过门教师稿做退化阶梯量出来的，不是推演出来的。

一、缺陷一：打乱句序完全测不出
   L4 在 v4 下 60/60 全过，软分 0.6993 vs 基线 0.7006。机理：六个软分项全是集合型的，
   逐项差 0.0000/-0.0016/0.0000/+0.0016/0.0000/-0.0243。
   修法：S7 orderPreserved = 稿中锚点按稿序在 raw 里位置的 Kendall tau 映射到 [0,1]。
   候选里判别力最好（AUC 0.786；锚点 LNDS 0.732，句质心 LNDS 0.556）。
   不是硬门：忠实稿自己也只有 0.798，任何阈值都会误杀好稿。

二、缺陷二：软分奖励删内容 —— 三个假设，两个被实测否掉
   L1（删末 25% 句）软分反而升高 0.7006 -> 0.7121；删掉的 107 句全是决策
   （条件分支 + 下一步计划）。六个维度没抓到的原因：被删句锚点 1.72/句 vs 保留 3.55/句
   —— 决策是锚点稀疏的散文，而六个维度里五个是锚点度量。
   · 假设"用决策句 n-gram 覆盖率"：完整稿覆盖率也只有 0.307，AUC 0.539 -> 否掉。
     原因是 raw 英文 / 稿中文，跨语言散文比对从根上不可行。
   · 假设"把 S4 到 target 封顶就够了"：L1 仍 0.7451 > 0.7379 -> 不够。
   · 假设"S3 用锚点口径是设计缺陷"：它是唯一跨语言可用的覆盖度量 -> 否掉。
   最终修法三处：
   1) S4 = 压缩量(到 target 封顶) x 锚点保留率。不新增任何阈值。
   2) S3 改成真的量决策：稿决策标记数 / (raw 标记数 x tokRatio)。
      原口径对"决策被删"的 AUC 只有 0.505/0.616（瞎猜），新口径 0.862/0.897。
      跨语言可用是因为标记词各算各的（raw: if/then/next，稿: 如果/那么/下一步）。
      风险如实记载：这是在散文上跑正则，只能进软分，永远不能变硬门。
   3) S7 新增。

三、权重：原六项逐字不动，新增 S7=.15，除以 1.15 归一（便于审计）。
   跨版本不可比，要比就两边都用 v5 重算（纯函数、零成本）。

四、阶梯修前/修后：L0 0.7006->0.7083 · L1 0.7121->0.6411 · L2 0.6898->0.6023
   · L4 0.6993->0.6906。现在完全单调。

五、真实数据（dev 89，v9 生成稿原样重算）
   教师 0.7030 -> 0.7069 · 学生 0.5740 -> 0.5381 · 过 G1 门后学生 0.5836 -> 0.5453
   师生软分差距扩大 0.129 -> 0.169，方向正确（v4 在掩盖学生）。

六、build-sft.mjs 加 --dev-ids：dev 必须冻结
   dev 是按仓库哈希切的，加新仓库会让 dev 变大，两轮成绩就没法比 ——
   两个数各自都对，放在一起比就是错的，且不会报警。
   钉住 dev 后还要把 dev 仓库的新单元挡在训练集外（防泄漏，泄漏只让 dev 虚高不报警）。
