# 尺子 v2（$0 候选）——结论：**淘汰**

日期：2026-10-11。文件：`ruler-v2.mjs`（规则）、`calibrate.mjs`（校准与评估）、`results.json`（全部数字）、`EXCLUDED-ruler-pass-ids.jsonl`（通过了被淘汰尺子的 43 条，**不是训练数据**）。

## 1. 规则（事先固定）

- 适用：raw ≥ 3100 字符（生产区间）。
- **R1 动作依据保留**：raw 末 300 字符中的代码式标识符（含 `/ . _`、驼峰或反引号，长度 ≥ 4，不在 ctx 中），在 draft 中以原样子串出现的比例 ≥ **τ = 0.8（固定，不下调）**。无 R1 事实 ⇒ 不过。
- **G2 凭空主张**：draft 反引号里的路径/标识符必须是 raw∪ctx 的子串；有一个不在即不过。
- **G3 压缩率**：len(draft)/len(raw) ≤ 0.5。
- 淘汰规则（事先定）：匹配稿在 dev 上的通过率 **< 0.5** ⇒ 尺子淘汰（"什么都不过的尺子不要"）。

## 2. 数据划分（无结局标签参与选择）

- **dev**：教师 v4-full 中 raw ≥ 3100 的 685 行（只读，无真机结局标签；只用于检查"能否区分匹配与错配"）。
- **负对照**：每条 draft 与另一条随机行的 raw+ctx 配对（固定种子）。
- **test（只报告）**：13 条金标中 raw ≥ 3100 的 8 条。gold 不参与任何选择。

## 4. 修订记录（诚实披露）

- **修订 1（2026-10-11，任何结局验证之前）**：首版 R1 抽取的是尾部的英文散文词（first、confirm、about …），不是动作依据。检查 `sse-truncated-s1-r3` 时发现后修正为"代码式标识符"。修正后通过率 6.3%，仍淘汰。**首版结果未被采用。**
- 未做任何其它调参。τ 未改动。

## 5. 结论与对 D1 / D2 的含义

1. 字面保留型尺子（R1）在 dev 和 gold 上都不能通过"通过率 ≥ 0.5"的下限，因此**按事先规则淘汰**。它不能作为真机成功的代理。
2. 同时，**gold 的良好稿也不过这把尺子**。所以它不只是"太严"，而是**测错了东西**：稿子是否好，不取决于是否原样保留了标识符。
3. G2（凭空主张）在 dev 上只有 0.479 通过，即约一半教师稿含有原文与上下文都没有的反引号标识符；在 gold 适用样本上只有 `perf-regression-s0-r7`（唯一可回放的 win）不过。G2 可以保留为**防幻觉门**，但它不能单独决定成功。
4. **没有可用的 $0 尺子。** D1 的"运行时模式"仍然开放，但**所有候选的有效性都需要真机结局标签**，只能通过阶段 2 的花费获得（D2 的 Clopper–Pearson 下界）。
5. **D6（训练数据）暂停**：没有通过校准的尺子，因此不产生任何训练数据。教师 v4-full 保持原样、未修改。

- 没有尝试其它候选规则。再试一个就是在测试集上找规则，不做。
