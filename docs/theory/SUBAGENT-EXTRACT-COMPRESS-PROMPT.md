# 副模型压缩提示词设计理论提炼（卷五 S1–S10 + 卷六）

> 源：同上文档第五卷 L1436–2089、第六卷 L2092–3012。⚠ R1–R11 所引原评测文件已随 `25d1140` 删除（L1739），读数只能作自报数据引用。

## 一、S1–S7 基础

- **S1（L1616–1630）**：副模型**不写出生文本**只输出 ops，措辞/长度/顺序/人称由代码决定；不变量失败 → **回退原文，永不回退 x1**（L1620）。**S7**：①②⑤⑥ 已落地，③④⑦⑧ 未实现（L1729–1731）。
- **S2（L1634–1656）**：字段全为**枚举或原文片段，没有一个数值**；副模型不打分。
- **S3 硬不变量（L1658–1668）**：I1 anchor 原文逐字；I2 标识符须逐字见于原文/工具输出；I3 REFUTED 必须 ev=tool 且带 alt；I4 非工具证据的否定一律降 SHELVED；I5 `src=tool:` 内容**永不写「我决定」**；I6 已编译文本永不作为副模型输入；I7 同 key 只一个当前值。
- **S4（L1670–1688）**：副模型 420 字；逐条判 k/ev/kind2/anchor（5–20 字原文片段）/被放弃的路写 alt+why（非工具观测则 SHELVED+trigger）/路径命令数字错误**逐字照抄**/**只标注实际出现的内容**。
- **S5 渲染（L1690–1712）**：证据定粘性（tool→陈述，derived→「目前判断」，guess→问句）；替代先行、X 最小具体度、X 只出现一次；标识符逐字全名无代词；跟随风格画像；工具来源只写事实带来源。层 B 原为「尾部 OPEN 问句」，**已被 R3 推翻**（L1701）。
- **S6 参数（L1714–1725）**：λ0=0.004、λ∈[0.001,0.02]、β=0.6、δ=0.0005、W=最近块、s_w,max=0.7、双编码 Δ>3·λ·tok。
- **机理（P1–P6，L1445–1597）**：动作锚 `actionLink`（L1453）；**替代先行**（L1488）；**体裁伪装**（L1510）；**自镜像**＝主模型自己会写的文本（L1582）；边界：风格镜像只作用于**形式**，不扩展成「它自己的判断」（L1597）。

## 二、S8 实测修订 R1–R11（观察 → 原则 → 措辞）

- **R1（2026-09-28）** 原文每块 1–7 句「若观察 A ⇒ 结论/动作」，产物 9/10 为 0 句 → op 模式缺**判读类**。新增 `IF{cond,then}`（≤4）、`READY{text,trigger}`（≤2），**必留且不受长度预算约束**（L1748, L1762）。
- **R2（同日）** 原文 21 句「修复/改为」，产物 0 句 → 缺「已备动作」，且「不给建议」被执行成**删掉候选改法**。规则须写「把候选改法写出来」（L1749, L1762）。
- **R3（同日）** 产物以「还没弄清的是…？」收尾，主模型**一律回头取证** → 块尾近因权重最大。**块尾放判读不放问题**；OPEN 写陈述；有判读时不再重复（L1750, L1763）。
- **R4（同日）** 零第一人称、满「目前判断/当时计划/来源」→「调试笔记体裁」与自镜像矛盾，「当时计划」被读成**过期记录**。改**第一人称内心独白**（我目前判断/我现在采用/判读：若…就…），I5 不变（L1751, L1765）。
- **R5** 静态 kind 权重未落地 v(i)＝实现问题（L1752）。**R6** 副模型**无视长度、复述可见回答、判读句已列仍漏标、语言判错** → **提示词约束不可靠**，长度只能靠门（L1753, L2263）。
- **R1′（it1）** 5/5 标出 IF 仍低于原文（4.6 vs 5.4，直改 30% vs 40%），失败的 IF 多是**机理条件句** → `Pol=P(o=o_k)·C_re`，cond 必须是**待回观察的可能结果**（若复现了/若 n 里有 model/若 finishReason=length），then 必须是结论或动作；问句与机理句不算 IF；「如果…再…」「…才…」也是判读句式（L1777–1787）。
- **R2′（it2）** 观察已证实主模型却先 read_file；主模型用到的 old_text **全部**逐字在原文，稿里一条没有 → C_re 还要含「重新拿到落点逐字文本的代价」。**闭合＝文件 + 逐字 `at` + 改成什么**；`at` 须原文子串，没引用就**省略、不许补写**（L1789–1795）。
- **R2″（it3）** 带锚点 eacces 两轮 9.0（原文 5.5）；无锚点 wrong-model 2.0/4.5（原文 9.0）→ **动作接口的粒度是行，不是标识符**。服务于待回观察后动作的**原文逐字代码行**（≤2 行、每行 ≤200 字）归必留，挂在判读/结论上；写成「我看过的相关代码」，**不宣称要改它**（L1797–1804）。
- **R4′（it4）** 思考 <800 字→直改 0%、800–2000→17%、≥2000→50%；原文想得短也失败 → 行式体裁是**理论内部错误**。层 A 改**连贯第一人称推理散文**（段落 + 所以/但/那么/如果…就…），**不用项目符号、不用「标签：」**；条目与逐字规则全不变（L1806–1814）。
- **R4″/R5（09-29，oracle 手写 3 轮）** A 5.8 / B（+「工具原文、逐字、可直接作 old_text」）6.1 / C（+**DeepSeek 原生语域**）**6.4、直改 70%、思考 4395**；A 失败样本只想 117–215 字读文件 → ①**归属**：被认作自己的推理 ⇒ 接着深想；②锚点须带**出处 + 逐字性声明**（真实陈述）。语域必须**真正原生**；「我判断/我现在采用」仍是外来笔记腔（L1823–1838）。
- **R6（直写路）** oD 4.8（「根因已明却继续取证」）；oE **5.5，wrong-model 10.0**；oF perf 10.0 → 可用句是**降低动手的核对成本**，须条件自动（锚点经门核真才补）（L1841–1847）。
- **R7（09-29，修正 R6 归因）** oracle 与自动稿「下一步」都是复现，差别全在**判读分支的动作项**：oC 分支内落点⇒edit 2/2 得 8.5；oE/oF 只有游离通用句⇒read 4/4 得 1.5–2.0 → **分支闭合与落点绑定可机械检查、机械修补**。规则：①落到改法的分支写「文件 + 反引号逐字落点（**写在分支句内**）+ 改成什么」，只写方向不算闭合；②可用句**绑在落点上、写在分支句内**，并接观察后仲裁（「看到结果后不用再读文件」）；③候选**只落定一个**：优先落点在手的，其次改动最小的，其余≤1 句搁置，**不写「A 或 B」**；④「下一步」必须与原文实际发出的调用一致（L1853–1895）。实测 oH flaky 8.5，4/4 直接 edit（此前 0/6）（L1896–1898）。
- **R8a/R8b/R9（同日第三会话）** perf 原话「可能没有加号，最好先 read_file 确认」（落点来自 diff `+` 行）；wrong-model 原话「Need to see normalizeRequest to confirm n.model」（思考 126 字）；sse 冒出稿没覆盖的新量 → ①**文件逐字**：逐字性是相对**将被编辑的文件**；②**三元组** `(path, old_text, new_text)`，逻辑改动的 new_text 就是设计工作；③trigger 须是**待回输出里会字面出现的特征**。写**已完成的核对句**（「diff 的加号是标记，文件里这一行是 `…`，old_text 不带加号也能匹配」）；每支点名「看到什么就够了、不再查什么」；落定次序**定义处优先于调用处**（L1900–1931）。实测 effect-19 三题 8.9/直改 100%/回头 read 0%（raw 5.0），new_text 被**一字不改**采用（L1938–1950）。
- **R10（同日第三会话晚）** 消融把「三条一起赢」拆开，**两条预测被证伪**（noNew 仍 3/3、noClose 仍 3/3；noPre 2/2 但思考 8010 vs 3697；noNote 掉到 1/2）→ ①动手前有**固定清单**（假设坐实/old_text 精确/改成什么/有无非看不可），**冗余闭合**是稳健性来源；②真中介是**本轮思考长度**，失败＝短思考 × 恰好问到未写明项；③R8b 降级：逻辑改动不该由关思考的副模型设计；④**反驳测试是形态的必要条件**（Goodhart 防线）。措辞：**把清单每一项都写成明文答案，不让主模型自己推**；换值改法写 new_text，逻辑改动只写一句意图；第二分支同样具体 + 逃生句「如果输出跟这两种都不像，先别改」（L1952–1977）。
- **R11（09-29 第五会话）** v4d5「理论完备」反降（6.5/7.0 vs v4d4 7.8）；sse 3/3 不落定（把 R10.3 读成「逻辑改动可以不落定」）；同提示词 flaky 9 vs 2（选择在 10k 字里随机）；落到含 `[DONE]` 的 if 行而非造 `'stop'` 的 return 行；样例专名 `pool.js` 被抄 ⇒ 整份拒绝 → ①**选择题化**：程序算出【在手代码行】放在原文之后，副模型从「10k 字里回忆」变成「≤8 行里挑」（能力上限由副模型定，**题目难度由我们定**）；②落定发生在**正文**；③new_text 必写（逼它落定那一下）。清单只取 read_file/cat/git diff/grep -n/sed -n，diff `+` 剥加号、`-` 排除、grep 剥「文件:行号:」，标**值行/值段/定义行/调用行/返回行**；规则明写**样例里的名字一个都不能出现在稿里**；落定句「改法只落一个：改 X 的 `那一行`，让它…」+「以原文**最后**的结论段为准」+「落点＝产生错误值/定义那个数值的那一行，不是提到关键词的那一行」+「值行优先于逻辑行、定义行优先于调用行、谁定义约定谁改」（L2009–2041）。实测 8.5/8.6，死路/错改/回头 read 全 0（L2046–2049）。

## 三、必须保留 / 必须删除

**必留（不受长度预算约束）**：IF（≤4）与 READY（≤2）（L1762）；服务于待回观察后动作的原文**逐字代码行**（≤2 行，≤200 字/行）（L1802）；分支三元组（L1919）；逐字 `at`，原文没有则省略（L1795）；值/定义处落点、**落点行随台账跨轮携带并标注观察时刻**（L2262）；已排除路+理由；猜测否掉的路带 trigger 挂起（L1881）；**已完成核对句**（L1918）；验收预注册（L2290）；状态声明 ≤ 程序判的状态（L2291）；第二分支（另一解释 + 不要改什么 + 逃生句）（L2035）；多轮延续段（≤4 句、增量）（L2288）。

**必删/禁止**：复述工具输出、自检、浅尝死路（L2060）；块尾 OPEN 问句（L1763）；项目符号与「标签：」（L1812）；第三人称与「当时计划」（L1751）；「A 或 B」与游离末尾的通用可用句（L1871, L1881）；diff `-` 行、`+`/`-` 与行号前缀当文件内容（L1916, L2041）；待证明假设作 trigger（L1925）；样例专名（L2038）；工具来源写成「我决定」（L1712）；台账与本轮观察之外的「事实」（L2278）。

## 四、下游模型会不会怀疑上下文、回头重测

- 「回头 read」是**摘要式压缩的通病**（JetBrains：LLM 摘要令轨迹变长 ≈15%），不是本项目特例（L1992–1996）
- **怀疑有三个触发点，都可消除**：(a) 逐字性不确定（R5 原话「先读全文确保 old_text 逐字匹配」）→ 用**已完成核对句**接住（L1834, L1918）；(b) 落点不在手/只有方向（R7）→ 绑进分支句（L1871）；(c) 冒出稿没覆盖的新量（R9）→ 预先说明「这不改变落点」（L1926）。
- **一句假担保使整句担保失效**：识破 diff `+` 行「可直接当 old_text」是假话后整句作废（L1907）；「这条观察是改后产生的」是**假的新鲜性担保**，把错误前提写成事实（L2397）⇒ 只允许**真实陈述**的担保。
- 成功样本都有自检句「要不要先读文件确认？——已有原文」，**稿里已完成的核对句正好接住它**（L1949–1950）；反驳题里观察与稿不符时主模型**会重新深想**（8243 字）——判读分支是真决策程序（L1975）。

## 五、长度预算与「长度服从保真」

- 保真度**由 v(i) 决定而非由位置决定**；收进末尾高 Pol 条目、去掉低价值项，同决策价值下 token 更少、干扰更小，**优于原样保留末尾 25%**（L1768–1771）。
- 层 A 下限 **800 字**（≈550 不够、≈935 更好，倒 U 上升段）（L1767）；**字数指令对副模型无效**，长度只能靠门（L2263）。
- 熔断：单步 1800→2000（稿 1600–1950）（L2041）；多轮合理 1800–2400，熔断 2600（L2451）。超长删法：**先删 K 项、后删三元组**（反之伤单步闭合）（L2415）；多轮延续段是增量、不重抄（L2292）；**λ 是唯一停止条件**（L1564）。

## 六、锚点 / 逐字引用 / 编造检测

- I1 anchor 逐字、I2 标识符有出处（L1662–1663），已并入 `fidelity.inventedIdentifiers`（L2651）。
- 逐字性**三级**：标识符级（S5 规则 3）→ **行级**（R2″）→ **文件级**（R8a）（L1804, L1915）。
- **观察逐字 ≠ 文件逐字**：diff `+`/`-`、grep/cat -n/sed -n 的「行号:」、节选统一缩进都是观察格式（L1916）。
- `new_text` 需**单独出处出口**（标识符来自原文/观察即可），否则整份稿被当发明放行（L1923）；程序部件列为合法出处 `programPartsText`（L2466）。
- 落点清单机检：`-` 行永不进候选、斜杠并列枚举（v11.9/v11.10）不当路径（L2041）；命中率 4/5 → 12/15 → **14/14**（L2027）。
- 反例：样例 `pool.js` 被抄 ⇒ 整份拒绝（L2038）；flaky 落到 distill.js 逻辑行而非值行 `hedgeAfterMs: 1600`（L2019）。

## 七、「压缩稿必须读起来像模型自己写的」

- **自镜像**：分布内程度最高的文本是主模型**自己会写的文本**；用自己风格写，困惑度最低（L1582, L1590）。**体裁伪装**：伪装成高频预训练体裁即分布内——陌生的不是「压缩」，是「没人这么写」（L1508–1510）。
- 「调试笔记」体裁被 R4/R4′ **证伪**（与自镜像矛盾，让主模型只想 137–538 字就去取证）（L1751, L1806–1813）。
- **归属机理（最终结论）**：原生语域散文被当成**自己的**推理接着用（低困惑度 ⇒ 当作已完成的思考），不必重推；带标签条目被当成**外部笔记**，需要复核，而复核＝取证（L1817–1820）；「归属」与「深度」是同一件事的两面（L1838）。
- 语域必须**真正原生**（C 稿 6.4 / 直改 70% / 思考 4395）（L1832）；形式跟随画像：语言、连接词、标识符包裹方式（L1586–1590）。
- **边界**：「写成它自己的风格」不能扩展成「写成它自己的判断」，工具来源仍须带来源（L1597）。稿的语域会被本轮**复制**（L1809）。

## 八、S9 / S10 多轮台账（要点）

- **S9（L2237–2266）**：终局＝跨轮**工作记忆纪律**，每轮拿到忠实、紧凑、**自己语域**的**工作台账**（证据逐字+出处/假设及状态/已排除+理由/下一步及判读分支/验收标准）。阶段 1 收官：v4d4 基题 8.5、反驳 6.5、错改 0、回头 read 6%、到位率 80%。三条结论：**冗余闭合**（缺落点才致命，选错落点不致命）；**担保的时效**（落点行随台账跨轮携带并标观察时刻）；**取证分支同样禁析取**（L2260–2263）。
- **S10（L2271–2466）**：`S_t=(F,H,X,C,Q,P,A)`，四弊端＝某栏没被表示（L2274–2281）。分工：**代码算它能算的**（P_t、C_t 状态、从**前几轮稿**逐字摘落定/排除/验收/三元组——**稿是机器可读的**），副模型只做「延续 + 增量 + 验收预注册 + 状态声明」（L2283）。四段形态见 L2288–2292；不变量 I-A…I-E 见 L2295–2299；**K1–K6** 见 L2403–2415（K3 措辞被读成改实现许可 ⇒ 改「**取证之前不动实现**」）。
- **S10.19 的上位规则**：**凡是能从台账与本轮调用确定性推出的句子，都不该让副模型写**（①③④三段半改由程序写）（L2455–2464）。另：H-ledger 不成立，机械台账单独无效——主模型缺的是**判读**（L2378）；言过其实须**宿主强制**，稿只能把状态摆出来（L2380）；`birthMinChars` 3100 下多轮循环几乎不触发压缩（L2358–2360）。

## 九、可直接落进提示词的十条

1. 块尾只放「若 A，就 B」，OPEN 写陈述（L1763）。
2. 全篇第一人称、原生语域散文，不用项目符号、不用「标签：」（L1812, L1832）。
3. 每个改法落到**一个**三元组：文件 + 反引号逐字落点 + 改成什么；不写「A 或 B」（L1876）。
4. 落点写值行/定义处，以原文**最后**的结论段为准（L2030）。
5. 逐字担保必须是真话；对观察格式的疑虑写成**已完成的核对**（L1918）。
6. trigger 用待回输出里会字面出现的特征；每支写「看到这就够了、不再查什么」（L1925–1926）。
7. 第二分支：另一解释 + 不要改什么 + 逃生句（L2035）。
8. 把动手前清单的每一项都写成**明文答案**（L1969）。
9. **样例是最强的教学，也是最强的污染源**——明写「样例名字一个都不能出现在稿里」（L2038）。
10. 只写有观测证据的证伪（REFUTED 需 ev=tool + alt），推断/猜测一律 SHELVED + trigger（L1665, L1680）。
