# 数据覆盖与下一批采集契约

2026-10-12。此表用于发现空白，不是现有语料已经支持这些能力。最终仍为任意出生 CoT 的原目标模型读回；首版能力范围必须明示。

| 轴 | 现有可用开发材料 | 缺口/下一批要求 |
|---|---|---|
| 任务 | 三个已知编码开发输入完整 AI 审查；六份 off-target 编码摘录 | 真实目标的逻辑/数学、阅读分析、规划等出生块；不把合成探针当真实覆盖 |
| 语言 | English raw / 中文任务 ctx / English 开发稿；合成中英/emoji 控制 | 目标中英文各层的真实 raw/ctx，混合代码/文本及原生 tokenizer 实测 |
| 长度 | 三个输入 raw 3.6k/4.1k/7.4k 字符左右；character proxy | 短、长、超窗、ctx 很长及低冗余输入；记录真实 token，不强截断 |
| 轮次 | 已曝光排障中后轮 | 早期多假设、中期反证、晚期待验/完成，冻结出生时间边界 |
| 信息结构 | 时序竞态、上限/目标区分、截断状态与拟做/已做 | 条件嵌套、例外、多主体、多分支、跨句因果与长依赖 |
| 量值与字符串 | 1500/1600、450/1800、finish_reason、paths | 相似但不等价的数值/标识符、大小写/Unicode、精确代码/不可压缩字符串 |
| 确定性 | 源 raw 本身多次改口/假设 | 正确/错误/冲突推理均采，参考不把假设升级成已证事实 |
| 工具/通道 | 旧 CFB capture；当前 hash 观测 opt-in | 用户实际宿主/工具 schema/provider 序列化及 reasoning 是否读入的版本证据 |
| 净收益/回退 | 未实测 | 不可压缩、高压缩损害、超时/越界/零收益案例，完整分母与累计成本 |
| 独立性 | 三个旧家族，不是新独立测试 | 来源 task/repo/template/provider call 族图；whole-family 隔离及 prior exposure |

## 每条 source admission 必须记录

- 合法来源/固定版本/原 harness、原始生成 prompt 血缘（未知就未知）。
- raw、压缩器 ctx 原字节 hash、ctx assembly/truncation 和出生/工具状态快照。
- 原始参考稿、修订稿、坏稿分开；许可和隐私的实际审查材料，不能只填 `clean`。
- 完整 source-fact annotation 与 `cfb.compression-review/1` sidecar：每个非空白源片段分类、重要事实精确 UTF-16 span、每个输出断言及支持/矛盾/不确定性。
- whole-family/split、既有曝光与用途；同输入多个好稿需等价/规范目标裁决。
- target 兼容证据。off-target 可以研究迁移，不可默认准入。
- 审查只有 AI1、人0、独立二审0；源世界事实未重执行、读回未测都明确注明。

当前 registry 的 `sourceAdmission` 全 false 是正确边界。新授权采集到目标 traces 后，先完成一小批全链，再依据失败结构扩大；没有行数阈值能保证 191M 会学好。

## 采集前不能缺的外部条件

1. 真实 reader 的访问方式、served version、是否允许 reasoning 通道读回、宿主及可保存状态。
2. API 或本地模型的明确预算/请求上限/重试纪律；不在文档/聊天粘贴凭据。
3. 目标 CPU/RAM/模型文件/时延/窗口约束，以及不占 128 MB 工作区的授权模型目录。
4. 合法任务来源和原始数据用途。公开可读不自动等于许可清楚。

合成对照可以测试标注/格式/反事实响应要求；它们不是替代这些外部条件的捷径。
