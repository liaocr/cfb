# 把 deepseek-v4.1-flash 的智能体表现推到极限：融合后的训练方案（v14.13，2026-10-02）

> 目标只有一个：主模型（权重冻结）在真实修 bug / 改仓库任务上的**通过率**显著上升，可复现、可留出验证。
> 本文件是检索（2026-10-02，见 §8 来源）+ cfb 四次实跑 + DSH 全部记录合起来的裁决与路线。先给结论，再给证据，再给流程与预算。

## 0. 结论

**权重不动时，让一个模型"突破"的手段文献里只有五类，而且有效应大小排序。** 全部搬进 cfb，按效应大小的顺序做：

| 层 | 杠杆 | 公开效应（同模型、权重不动） | cfb 现状 |
|---|---|---|---|
| ① 选择层 | 每题跑 k 条轨迹，用**执行裁判**（复现测试 / 回归测试）过滤，再用**无执行裁判**排序，淘汰"腐烂 / 过度思考"的轨迹 | CodeMonkeys：随机选 45.8 → 测试投票 + 选择 57.4（oracle 69.8）；RETRACE 训练免费的独立核验 +3.6～+7.0 Pass@1（同算力的 Self-Refine 为 0）；R2E-Gym 混合裁判 34.4 → 51 best@26；rot-aware 拒绝采样 +2.6～4.9；MaTTS k=5 +5～8 | **没有**（每题 1 条，n=1 下结论） |
| ② 工具面 / 协议 / 效力 | 官方 harness 极简模式的面（一句训练句 + bash + str_replace_editor）+ 原生 tool_calls 协议 + **全量交错思考**（官方契约）+ `reasoning_effort=high` | DeepSeek 自己的 DeepSWE / Terminal-Bench 分数就是在这个极简模式下跑出来的；SWE-bench Verified 非思考 73.7 → high 78.6 → max 79.0；MiniMax-M2 保留历史思维链 vs 丢弃：SWE-bench +2.2、Tau² +23、BrowseComp +12.6；AutoForge RL 消融同向 | v14.13 已落地面与协议；效力参数未接；历史思维链一直是全量（对的） |
| ③ 流程层 | **复现优先**（先写能复现 bug 的测试再改）、宿主事件门禁（改了必验、宣称前必验、找够证据就动手）、外部清单而非自检 | CodeMonkeys / Agentless 的生成都强制"测试与改动成对"；context-rot 白盒研究：外部清单 10/10 vs 通用自检 5/10；DSH dea48c68 门禁全触发全服从 | v14.13 已落地 gate 臂；复现优先未做 |
| ④ 经验层 | 跨题经验库：从**失败与成功**里蒸馏策略条目，带有效 / 有害计数，user 角色近场注入，留出题上验 | ReasoningBank（Gemini-2.5-flash）SWE-bench Verified 54.0 → 57.4、步数 −2.8；ACE +10.6 智能体任务；Training-Free GRPO 冻结 DeepSeek-V3.1 +4.6 | DSH 的 12 法则是手写版、无对照；cfb 未做 |
| ⑤ 上下文层 | 只在轨迹**变长**后触发：保留最近 N 轮全文，更早的思维链压成决策台账，工具输出裁短 | 长程搜索的 context-rot 研究：丢旧思维链能减少"放弃 / 过早给不确定答案"，但步数变多；**keep-latest + 摘要**是最好的成本–腐烂折中；OpenHands / JetBrains：摘要历史 54 vs 53（不伤、也不提） | cfb 的压缩器每轮都压、题只有 ≤8 轮 ⇒ 永远量不出它的价值 |

**对你两个论断的裁决**：
- 「历史思维链必须」——**对**。DeepSeek 官方契约：带 tools 的请求必须把之前所有轮的 reasoning_content 传回，否则 400；MiniMax 消融给出了量级。所以 `drop` 臂只是对照，不是候选。
- 「思维链里真正有用的少，冗余有负面效果」——**只在长程成立**。短题（≤8 轮、<60k tokens）上四次实跑都没量出任何差别，是因为那里根本没有腐烂可治；长程（几十轮、>100k tokens）上文献有腐烂证据。结论：压缩器不是每轮跑的东西，是**阈值触发**的上下文管理器，而且永远不碰最近几轮。

**预期**：在一个有裁判的 20 题长程切片上，②+③ 把 pass@1 抬到官方面的水平，①（k=2～4 + 裁判）再给 +5～10 个点，④ 再给 +3～5；⑤ 只在 >100k 的轨迹上贡献，且主要是成本与"不放弃"。这是文献区间，不是承诺；每一层都预注册，达不到就砍。

## 1. 架构：五层各自是一个可控变量

```
           ┌────────────────────────────────────────────────────┐
  任务 ──▶ │ ② 面/协议/效力  一句训练句 + bash + str_replace_editor │
           │    tool_calls 原生协议 · 全量交错思考 · effort=high    │
           ├────────────────────────────────────────────────────┤
           │ ③ 流程  复现优先：先写失败测试 → 改 → 跑到通过      │
           │    宿主门禁 act / batch / verify（user 角色近场）      │
           ├────────────────────────────────────────────────────┤
           │ ④ 经验  手册条目（≤12 条、因果式、带计数）近场注入     │
           ├────────────────────────────────────────────────────┤
           │ ⑤ 上下文  >阈值才触发：keep-latest N 轮 + 旧轮台账     │
           └──────────────┬─────────────────────────────────────┘
                          │  × k 条并行（k=2～4）
                          ▼
           ┌────────────────────────────────────────────────────┐
           │ ① 选择  执行裁判（复现测试 + 回归测试）过滤           │
           │         → 无执行裁判（flash 关思考，RETRACE 式重构核验）│
           │         → 淘汰腐烂 / 过度思考（放弃、空 diff、探测轰炸）│
           └────────────────────────────────────────────────────┘
```

每一层在 traj-run 里都是一个开关或臂，所以可以一次只动一个变量，也可以做 2^k 部分因子（`plan-bench --factors` 已有）。

## 2. 每层的具体做法

### ② 面 / 协议 / 效力（已落地 80%）
- `--aci rl-native --tool-protocol native`（v14.13）。差一项：官方极简模式的 bash 是**持久 shell**（300 s 超时、无网），我们的是每次新 shell；对 bugfix 影响小，记在案。
- 新增 `--effort low|high|max`（透传 `reasoning_effort`）。缺省 **high**：官方 high → max 只差 0.4 分却多花很多；"Prompt-Induced Waste" 的硬题战役里 xhigh 被 high 支配。
- 采样：官方建议 temperature 1.0 / top_p 0.95（思考模式下其它采样参数被忽略）。k 条并行的多样性来自模型本身的随机性。
- 历史思维链：全量传回（契约）。不做任何每轮压缩。

### ③ 流程
- **复现优先**：任务提示词里只加一句事实性要求「先写一个能复现问题的最小测试并确认它失败，再改；改完让它通过并跑原有测试」。这是 CodeMonkeys / Agentless 的生成形态，不是"深度思考"类的提示（那类提示被证明只增加工作量不增加成功）。
- **宿主门禁**（已落地）：act / batch / verify。再加一条 **外部清单回显**：每轮工具结果末尾附一行「任务：<首条用户消息前 200 字> · 已改 <n> 处 · 最后验证 <命令/未验证>」——context-rot 研究里外部清单 10/10 vs 自检 5/10，Manus 的 todo 复述同理。零 API。

### ④ 经验层（手册）
- 格式照 ACE：条目 = {触发条件, 做法, 为什么, helpful, harmful}，≤12 条、每条 <60 字、只写因果与顺序，不写要求清单（DSH 6000 字清单 → 加灯风暴；200 字 → 61 步，倒 U）。
- 来源：**失败轨迹优先**（ReasoningBank：失败条目把 46.5 → 49.7）。第一批种子来自 t8/t9/traj1–3 的失败与 DSH `DETAIL_GUIDE.exec` + 排错因果顺序。
- 注入：user 角色近场、每轮最多一次、带「这不是用户输入」头（DSH 公理 4：近场 vs 远场推理字符 20 倍差）。
- 策展：由我做 Reflector / Curator（零 API）；每条按留出题结局更新计数，harmful > helpful 两次即删。
- 与红线的关系：红线禁的是往**压缩器提示词**堆规则刷评委分；手册是给**主模型**、按结局判、带计数、留出题上验——需要你明确认可这是另一种对象。

### ⑤ 上下文层（压缩器的新岗位）
- 触发条件：上下文 > T tokens（起步 60k）或轮数 > R（起步 15），否则**不动**。
- 动作：最近 N=4 轮全文保留；更早的轮：reasoning_content 换成程序台账 + 副模型稿（现有生产压缩器，G2 决策不变闸照旧），工具输出裁到尾部 2k。
- 契约：字段仍然传回（不是丢），内容是稿。
- 量法：只在长程题上量；指标是 pass@1、放弃率、空 diff 率、成本。

### ① 选择层（最大的一块增量）
- 每题 k 条（起步 k=2，预算允许 k=4）。
- 过滤 1（执行）：轨迹自己写的复现测试 + 仓库原有测试；没通过的淘汰。
- 过滤 2（腐烂 / 过度思考）：放弃、空 diff、宣称未验证、同一探测 ≥3 次无修改、单轮并发动作 ≥4 的轨迹降权（Overthinking：选 k=2 里过度思考低的 +30% / −43% 成本；rot-aware 拒绝采样 +2.6～4.9）。
- 排序（无执行）：flash 关思考做 RETRACE 式核验——给它 issue + 轨迹 + patch 让它重构"这个 patch 解决的是什么问题"，与 issue 对照，不一致则 revise 或降权。注意 R2E-Gym 的教训：无执行裁判会过度看思维链、少看 patch，所以它只在执行过滤之后排序。
- 选择层不改任何一条轨迹，是纯宿主逻辑；对任何面 / 手册 / 上下文策略都叠加有效。

## 3. 训练流程（权重冻结下的"训练"= 用结局更新宿主侧的东西）

每一代（gen）：
1. **跑**：留出外的题 × k 条 × 当前策略（面 / 门禁 / 手册 / 上下文阈值），记录全部轨迹（含 finish、effort、每轮思考字数、动作数）。
2. **判**：执行裁判给每条轨迹结局；选择层给每题一个提交。
3. **反思**（我，零 API）：对失败轨迹按"傻子 / 天才"模式表标注（写完直接跑全量不先过小例 / 症状修补 / 发明题面外假设 / 边界忘光 / 卡壳撞墙…）；对成功轨迹提取可迁移的因果步骤。
4. **策展**：手册条目增删改，带计数；门禁规则只按触发-服从-结局三元组调阈值；上下文阈值按腐烂指标调。
5. **留出验证**：在留出题上只量，不改；Thresholdout 口径，e 值采纳（仓库已有）。
6. **提升**：赢过对照的进 `docs/presets/`（将来直接装回 DSH 预设）。

每代的数据都存回 `.cfb-runtime/traj/`，子状态 / 金标 / 效度账本沿用。压缩器只在第 ⑤ 层被调用。

## 4. 基准：没有长程 + 裁判的题，一切都量不出来

现有 5 个家族 ≤8 轮，只能测 ②③ 的"落不落子"和选择层的 pass@k。要看到"突破"，需要：
- **swe-slice**：从 SWE-bench Verified 里挑 20 个**纯 Python、pip 可装**的实例（sympy / requests / pylint / flask / pytest / sphinx / xarray / seaborn 这类，不要 matplotlib / astropy / scikit-learn 的编译依赖），固定种子，FAIL_TO_PASS / PASS_TO_PASS 作隐藏裁判，仓库 checkout 到 base_commit。零 API 可建；每条轨迹 20–40 轮，正是腐烂与选择起作用的区间。
- 你的 **oj-bench**（Boats! 等，40 测试点）如果还在，是第二个带裁判的家族。
- cfb 现有家族继续当冒烟测试（便宜、快）。

## 5. 预算（决定能跑多少）

| 通道 | 一条 30 轮轨迹 | 20 题 × k=2 × 2 臂 | 备注 |
|---|---|---|---|
| a6api 中转（现在） | ≈ $0.25–0.4（按仓库成本模型 $0.0125/次主调用） | ≈ $20–30 | 还有 20% 空思维链重试、预检 2–4 分钟 |
| **官方 api.deepseek.com** | ≈ $0.02–0.04（输入 $0.14/M、缓存命中 $0.0028/M、输出 $0.28/M） | **≈ $2–3** | 契约被强制执行、缓存 50× 便宜、无空思维链 |

结论很直接：**要出成果，先换官方端点的 key**。同样几块钱，中转只够跑一个家族的 n=1，官方够跑完整的 20 题 × k=2 × 两臂并留出验证。代码侧只是 base_url 变了，preflight / 携带检验照跑。

## 7. 不做的事

每轮压缩短题的思维链；把评委 Likert 当信号；"深入详述思路 / 多想几个方案"类提示（已被预注册研究证明只加工作量）；effort=max 常开；n=1 下结论；在中转上跑大样本。

## 8. 来源（2026-10-02 检索）

- DeepSeek 思考模式文档：带 tools 必须传回全部 reasoning_content，否则 400；`reasoning_effort` low/high/max；思考模式忽略 temperature 等。
- DeepSeek-V4-Flash 模型卡 / 报道：SWE-bench Verified 73.7（非思考）/ 78.6（high）/ 79.0（max）；代码智能体分数在 DSH **极简模式**（一句训练句 + bash + str_replace_editor、无压缩、max effort、temperature 1.0 / top_p 0.95）下评测；定价 $0.14 / $0.0028（缓存）/ $0.28 每 M。
- MiniMax-M2「Interleaved Thinking」：保留 vs 丢弃历史思维链 SWE-bench 69.4 vs 67.2、Tau² 87 vs 64、BrowseComp 44.0 vs 31.4、GAIA 75.7 vs 67.9；AutoForge（arXiv 2512.22857）RL 消融同向。
- CodeMonkeys（arXiv 2501.14723）：并行 + 串行扩展，测试投票 + 选择 57.4 vs 随机 45.8 vs oracle 69.8。
- RETRACE（arXiv 2608.08950）：训练免费双向重构核验，Pass@1 +7.0 / +3.6，Self-Refine 同算力无效。
- R2E-Gym：执行裁判 + 无执行裁判混合，34.4 → 51 best@26；无执行裁判过度依赖思维链。
- ReasoningBank（ICLR 2026）：SWE-bench Verified 54.0 → 57.4、步数 21.1 → 19.8；失败条目有增益；MaTTS。
- ACE（arXiv 2510.04618）、Training-Free GRPO（2510.08191）、Dynamic Cheatsheet（2504.07952）：经验库对冻结模型的增益与 brevity bias / context collapse 警告。
- Diagnosing and Mitigating Context Rot in Long-horizon Search（arXiv 2606.29718）：丢旧思维链减少放弃但增步数；keep-latest + 摘要最优；rot-aware 拒绝采样 +2.6～4.9。
- When and How Context Rot Appears in Coding Agents（arXiv 2607.17937）：8/10 vs 3/10；外部清单 10/10 vs 自检 5/10。
- LOCA-bench（arXiv 2602.07962）：清工具输出 / 清旧思维链 / 压缩在极端长上下文下可提升成功率。
- Prompt-Induced Waste in Coding Agents（arXiv 2608.01347，预注册）：要求"多方案 / 更深分析 / 更确定"的提示只增加推理与验证量不增加成功；硬题上 low → high 有救援（12 → 19 / 25）、xhigh 被 high 支配；同题重跑方差大。
- The Danger of Overthinking（2502.08235）、Thinking vs. Doing（2506.07976）、Sleep-time Compute（2504.13171）、OpenHands condenser / JetBrains observation masking：见 DSH-MERGE §1。
- SICA（2504.15228）：脚手架自改 17 → 53（主要来自编辑 / 导航工具改进）——工具层 > 提示层。
