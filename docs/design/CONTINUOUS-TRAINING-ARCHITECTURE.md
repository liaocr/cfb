# 持续训练架构（v14.0，2026-10-02）

> **v14.2 更正（2026-10-02）**：本文件描述的 v14.0 环路在三处断开——候选生成是在固定前缀上贴补（6 臂 2 份文本、K1 不在前缀里、截断发生在 K 项之前）、
> 奖励是未校准的评委 Likert 加权和、`cfb-cycle run` 到出候选组为止且 `feedback()` 的观测数恒为 0。
> **现行闭环以 [`CLOSED-LOOP-V2.md`](CLOSED-LOOP-V2.md) 为准**：生产等价候选、任务真值维 + live 结构分、序贯配对、`plan → run --live --v9 → ingest → propose` 全在代码里。
> 下文 §4 / §8 的 `cfb-cycle run`、`scoreCandidates`、`activeSelect`、`feedback` 流程已被替换，保留作背景；§1 判断层的维度定义仍有效，但评委维降为诊断、不再是选择信号。

> **目标**：一台可以一直往下练、不断迭代、逼近上限的机器。
> **三条硬约束**（用户指令）：① 判断层必须科学可量化；② 判断层上限必须高，不能轻松练到顶；③ 必须保持大模型参与，不能完全交给写死的规则。

---

## 0. 先回答"为什么这样设计"

上一版的离线层做了**语料、判据、候选、出价**，但它有一个致命的结构缺陷：
**候选空间是 7 个版面旋钮，而理论说的最大杠杆一个都不在里面。**

| 杠杆 | 理论出处 | 已知效应量 | 旧版在不在候选空间 |
|---|---|---|---|
| **可推导的预见 K1–K6** | S10.14 / S10.18 | 红题 **4.9 → 8.0** | ❌ 不在 |
| 逐条信息取舍 v(i)=D·Pn·(1−R) | 卷四 A2 | 未测 | ❌ 不在 |
| 死路处置 REFUTED/SHELVED | 卷五 P4 | 未测 | ❌ 不在 |
| 版面/人称/长度/记号 | 卷三、卷二 | 未知（可能很小） | ✅ 只有这些 |

**所以上一版是在"已知最大的杠杆"之外做搜索。** 本版把优先级倒过来。

## 1. 判断层（本架构的重心）

### 1.1 科学可量化

每个维度必须有四样东西，缺一不可（`test/judge-calibration.selftest.mjs` 测试 02 强制校验）：

| 要素 | 含义 |
|---|---|
| **定义** | 一句话说清测什么，不含糊 |
| **刻度** | 区间与步长，例如 `[0,10]` |
| **锚点** | 0 / 中位 / 满分各是什么样，这是**不同评委对齐刻度的唯一依据** |
| **评分者** | `code`（确定性可推）还是 `llm`（需读懂语义） |

### 1.2 上限必须高

这是本版最重要的一个设计决定，有**定量依据**：

| 判据形式 | 状态空间 | 信息量/次观测 |
|---|---|---|
| 二值（"是否假完成"） | 2 | **1.00 bit** |
| 三档（`claimOfV3`） | 3 | 1.58 bit |
| 0–10 序数 | 11 | 3.46 bit |
| **本判断层（9 维向量）** | **9,856** | **13.27 bit** |

**二值指标的问题不是"不够准"，是"太容易到顶"**：一次观测只给 1 bit，n=20 就摸到天花板，
后面的迭代自然就不明显了——这正是用户担心的事。

本判断层一次给 13.27 bit，**分辨率是二值的 13.3 倍**，天花板远高于当前水平。

最低可分辨效应（`pairedBootstrap`，σ≈1 刻度，双侧 95%）：

| n | 可分辨的 Cohen's d | 含义 |
|---|---|---|
| 5 | 1.25 | 只能看到巨大差异 |
| 10 | 0.89 | 大效应 |
| 20 | 0.63 | 中到大效应 |
| 50 | 0.40 | 中效应 |
| 100 | 0.28 | 接近小效应 |

对比二值判据：n=20 时只能分辨 >40 个百分点的差异。**同样的钱，这个判断层能看见 10 倍细的结构。**

### 1.3 必须有大模型参与（分工原则）

> **代码负责「能从上下文确定性推出」的量；评委负责「需要读懂语义」的量。**

| 维度 | 谁测 | 为什么 |
|---|---|---|
| `formClosed` 形态闭合 | code | 段落在场与否是字符串问题 |
| `kCoverage` K项覆盖 | code | K1–K6 是可枚举的结构 |
| `invention` 发明标识符 | code | 集合差，确定性 |
| `evidenceSufficiency` 证据充分度 | **llm** | "三样证据各有出处"要读懂语义 |
| `actionResolve` 动作分辨力 | **llm** | "先确认落地 vs 从代码推断应该好了"是语义判断 |
| `foresight` 前瞻正确性 | **llm** | 预写的分支在该情形下是否可执行 |
| `stateCalibration` 状态相称性 | **llm** | 声明的状态是否超出证据支持 |
| `infoDensity` 信息密度 | **llm** | 区分"新信息"与"复述可见输出" |
| `redundancy` 冗余率 | **llm** | 同上 |

**6/9 的维度由评委测。** 这不是补充，是主体——因为"衡量、归因、修改"这三步，
用正则写不出来。代码只做它能做对的那 3 个维度。

**两者必须交叉验证。** `ruleLlmDisagreement` 专门抓这种情况：
> 规则侧说「发明标识符很多」，评委侧却说「证据充分」⇒ 其中一方错了，该样本送人工裁决。

**分歧本身就是信号** —— 要么规则太粗，要么评委在幻觉。这是把"代码"和"AI"放在一起的真正理由。

### 1.4 一致性是可测量的

`raterAgreement` 给每个维度报标准差与 ICC(1) 近似。
综合分极差 > 5 说明**该样本的评委分歧足以改变结论**，应加票或送人工。
这不是事后解释，是**事先设定的作废条件**。

## 2. 生成层：候选来自杠杆，不来自旋钮

`tools/helpers/levers.mjs` 按**理论效应量**排序：

| 优先级 | 杠杆 | 取值 | 理论依据 |
|---|---|---|---|
| **1** | `kItems` | off / core / all | S10.14（最大效应量 4.9→8.0） |
| **2** | `selection` | keepAll / balanced / strict | 卷四 A2 v(i)=D·Pn·(1−R) |
| **3** | `deadEnd` | drop / shelveOnly / paired | 卷五 P4 |
| 5 | `layout` / `length` | — | 低优先（旋钮降级到此） |

**纪律：一轮只动一个杠杆**（`ablationSet` 在测试里强制校验"只允许一个杠杆变化"），
否则归因不出来。`layeredSet` 每轮每个杠杆推进一格，用于渐进探索。

**关键实现**：K 项与死路处置都是**结构性**的，所以变体可以由程序对已有稿施加变换得到
（`applyKnobs`），**不需要重新调用模型**。这让消融实验可以完全离线完成。

## 3. 打分与校准层

### 3.1 打分必须可归因

`compositeScore` 返回的分数**等于各归因项之和**，可逐项打印。
方向统一由 `normalizeDims` 负责（"越小越好"的维度转成质量分），
**权重一律非负**——传入负权重会被直接拒绝：

> `weight-must-be-nonnegative`（因为方向已统一，负权重会静默反转语义）

> **这是本轮抓到的一个真实 bug**：旧实现把「归一化方向」与「负权重」混用，
> 导致 `invention=0`（最好）被归一化成 1.0，再乘 −18 ⇒ **发明标识符越多，分数越高**。
> 即打分器会偏好充满幻觉的稿。测试 05 抓到了它。

### 3.2 权重由真实结果拟合，不是人工设定

`fitWeights` 用**岭回归 + 留一交叉验证**：

- **样本 < 4 ⇒ 拒绝拟合，收缩到默认权重**（"不因小样本而宣称学到东西"）
- 输出 `R²`、`looRmse`、`confidence`（low/medium/high）
- 负系数被钳到 0 并报 `clampedNegative`（共线性过拟合，不是"反向维度"）

### 3.3 越练越准的验钞机

`rankAgreement` = **离线排序 vs 真实结果的秩相关 ρ**。
这是判断"回灌是否真的起作用"的唯一指标，而不是感觉。

### 3.4 发现"缺维度"——这是改进生成层本身的机制

`missingDimensionSignal`：如果**真实结果最差的样本，在特征上却接近最好的样本**，
那说明**现有维度解释不了它们** ⇒ 缺的不是某个取值，是**缺一个维度**。

这是整个架构里最容易被忽略、但最重要的一环：它让机器能**改进自己的候选空间**，
而不只是在给定空间里找最优。

## 4. 编排层：一轮怎么转（v14.0 原文；**已被 v14.2 替换**，见 CLOSED-LOOP-V2.md §1）

v14.0 的 ①–⑦（corpus → judge → `cfb-cycle run` 出候选组 → `scoreCandidates` → `activeSelect` → effect-ready → `feedback`）
在代码里只走到 ③：候选组不进 `effect-ready` 的计划，`feedback` 没有观测。v14.2 的实际环：

```
champion.json ─→ ① candidates.mjs 成稿（control = 生产重编译；candidate = +1 杠杆；过闸；退化标出）
              ─→ ② truth-dims.mjs 离线裁决（安全过滤 / 方向校验 / 可用 ≥3 题；不排序）
              ─→ ③ cfb-cycle plan 冻结 v9 计划（13 请求、≤USD 1、预注册）── 停，等批准
              ─→ ④ effect-ready run --live --v9 --round N（唯一花钱的命令）
              ─→ ⑤ cfb-cycle ingest（配对胜负 → Beta 后验 → adopt/reject/continue → history.json）
              ─→ ⑥ adopt ⇒ champion 换新 ⇒ 下一轮 control；propose ⇒ 生产 diff（不写 src）
```

主动学习（探索/利用 0.6/0.4）与 `missingDimensionSignal` 未进 v14.2 的环：5 对/轮的样本量撑不起它们，先把环转起来。

## 7. 诚实清单：这套架构**还没有**证明什么

1. **判断层的 13.27 bit 是"容量"，不是"效度"。** 维度多不代表测得准。
   效度需要"离线分 vs 真实结果"的 ρ 来证明，而**现在观测数是 0**。
2. **评委维度从未与人工裁决对齐过。** 锚点写了，但没有校准样本，刻度是**悬空的**。
3. **`missingDimensionSignal` 的阈值（0.35）是拍的**，未经数据验证。
4. **主动学习的探索/利用比例（0.6/0.4）也是拍的。**
5. **`actionResolve` 的 0–10 刻度**是照 run4 的既有用法写的，不是独立标定的。
6. **K 项的效应量 4.9→8.0 来自历史文档**，本架构只是把它变成可测，**没有重新验证**。
7. **三个杠杆（selection / deadEnd / 宿主接口）的候选只是外壳**——
   `selection` 目前只改 `minV` 参数，**没有真正实现卷四 A2 的逐条 v(i) 计算**。

第 7 条尤其要强调：**杠杆列表里有，不等于杠杆已经建好。**
`kItems` 是真的（文本可开关），`selection` 目前还只是参数占位。

## 8. 接上 API 之后的第一步（v14.2 更新）

```
node tools/cfb-cycle.mjs doctor                           # 9 项预检
node tools/cfb-cycle.mjs plan --pricing eval-pricing.json # 零 API：成稿 → 离线裁决 → 冻结 v9 计划 → 打印预占/实付/每 bit 价 → 停
node tools/channel-check.mjs ...                          # 逐次 canary（商户不稳就别开）
node tools/effect-ready.mjs run --live --v9 --round 1     # 人批准后；≈ USD 0.13 实付 / 0.50 预占
node tools/cfb-cycle.mjs ingest --round 1                 # 配对 → 后验 → 判定；adopt 改 champion
```

这就是让「观测数从 0 变成 5」的第一步；第二轮起 `plan` 自动以新 champion 为 control、后验跨轮累积。详见 CLOSED-LOOP-V2.md。
