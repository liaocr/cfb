## 4. 四轮侦察要点汇总（可直接引用）

### 4.1 六面墙（轮 1）
① 文本通道是最有损的介质（KV/latent 是白盒上限）；② token 记忆 ≪ 训练出来的记忆（Cartridges/LCF：13MB adapter > 956MB，+23 EM）；③ 目标"像不像好摘要"是错的（CORE-RAG：无金标摘要，用下游 EM/F1 当奖励）；④ 输入才是瓶颈（Reasoning Theater：强制回答能分辨"剧场"；CoT 是计算不是装饰）；⑤ 陈述不能取证（TraceRepair/TraceCoder：只有探针/动作能取证）；⑥ 生成≠自验证（2602.07594）。理论拼图：双模拟 / Wyner–Ziv 侧信息 / 任务导向率失真 / 多描述。动作 A–E：B 分层多描述 → C 编译期充分性自检 → A 剧场判别 → D 探针回填 → E 状态住进稳定前缀。

### 4.2 六个突破 + S0（轮 2）
- **诊断**：Meta-Harness 把文本优化器的核心失败模式总结为 "**compression is the core failure mode**"；ACE 命名 brevity bias + context collapse（18,282→122 tokens）；ICLR 2026 信息率 = MI/token 与下游 r=−0.84（我们还在用贵而糊的同族 Likert）。
- ① **制品可训练**：SkillOpt（2605.23904）技能文档当参数——有界增删改 + 文本学习率 + **严格留出门（平局拒绝）** + 拒绝编辑缓冲；52/52 格最好或持平；$1–5/技能。GEPA（2507.19457）反思 + Pareto > GRPO（+6%，rollout 少 35×）。
- ② **产出 = 可执行义务**：PIS（2609.01272）(trigger, action, status) 三元组 + 代码生命周期，PM-Bench 65.1%→82.9%；AgentSpec/VeriGuard/Agent-C 运行时强制。
- ③ **harness 端搜索**：Meta-Harness（2603.28052）同模型 harness 差最高 6×；DGM 归档 + 目标黑客警告；ADIAS issue manager。
- ④ **留什么靠测量**：ContextCite 32–64 次消融给逐源归因；Thought Anchors：规划句/不确定句最承重（与我们正则相反）。
- ⑤ **跨会话库**：DreamCoder 的 MDL 压缩压力（我们库=0）。
- ⑥ **测试时搜索**：F(N)=F_max(1−(1−p)^N)，N=10–20 + 轻量验证器 ≈70–80% 收益；瓶颈是验证器质量。
- **前置条件 S0**：合成 20–40 题留出任务族 + 确定性判据 + 三分切。**没有它，①③⑤ 无法单调改进。**

### 4.3 三族突破 + 硬反证（轮 3）
- **A 引出**：VISTA（2606.30005）类型化块 + 仪表盘 + 无损存档/恢复，训练零成本，LOCA-Bench 22.7→50.7%，增益随压力增长；Voyager 可执行技能库（去课程 −93%、去自验证 −73%，**库在后期才发力**）；ReasoningBank（ICLR26）+8.3pp 且 **k=1 最优、k=4 反降**；AgentEvolver 自提问 15.8→36.1（7B）。
- **B 验证优先**：生成↑ ⇏ 自验证↑；**训练自验证反哺生成**；STV 用参考解当特权信息（≈2×；ViL +33%，去掉验证器生成器仍 +30%）；ExecCritic 结构：测试-验证-修复三段 + **修复期间冻结测试**（61.2→72.6%）。
- **C 循环控制**：自训练 rise-and-collapse 需 **CARE 迁移门 + 早停 + 归一化** 组合；峰值 checkpoint；**错误历史隔离**；反馈二元化（Feedback Friction）。
- **硬反证（必须遵守）**：SkillsBench——**人写技能 +16.2pp、LLM 自写 0 增益**；agent 自写测试净收益 0（~500 任务，变化为零）→ 关键词是"**独立**"，不是"写测试"。
- 顺序 **V→E→C**。

### 4.4 机制层（轮 4，最重要）
- **局部最优是表示 + 邻域算子诱导的**（AAAI 2000）；换表示 = 换搜索空间：FunSearch 搜**程序**不搜解（Nature 2024，cap set 512、下界 2.2180→2.2184、140 次实验 4 次命中）；AlphaEvolve 代码空间 + MAP-Elites 档案"防过早收敛"（48 乘法、ω 2.371339→2.371177）。
- **端到端 S=Πp_i，∂S/∂p_i=Π_{j≠i}p_j**：任一因子≈0 ⇒ 其余改进导数≈0。这就是"反复修改、有限且零碎"的数学形态；我们 run4 的表（sse 0→8.5、perf 5.5→9.0 vs wrong-model 9→9）就是它的实例。
- **被动是理论劣势**：主动 O(log 1/ε) vs 被动 Ω(1/ε)；教学维度：线性概念 1–2 条样本即可教会（10,000 维 SVM 单条样本，rel err 1e-4）；BED-LLM 按信息增益选问题 +37.4pp；GenEnv ZPD 40–60% 带 3.3× 数据效率。
- **跳变发生在结构不在参数**：grokking 逃逸 ln τ ∝ B/(η·lr)；球面拓扑 54,160→2,480 epoch；涌现 = 学会稀疏注意力模式，**patch 数个头可提前引出**。
- **已发表系统的共同五列**：制品可机器检查 / 独立评估器 / 档案多样性 / **回滚是一等公民** / 验证预算 ≥ 生成预算。**我们一列都没有（制品是散文）。**
- 反证与限制：技能库会腐烂（0.26 vs 0.58，1/5 技能有害，效果**有符号**且平均相消）；过度自省有害（λ_ref>0.2）；越界大跳变更糟；命中率低；搜索放大作弊；提示词只能建议不能保证。

## 5. 结论与方案（R1–R4，用户已批）

**诊断**：我们优化的对象（中文散文）**不可机器检查**，因此评估器/档案/回滚/验证预算全都无法成立；能拿到的分数只是"散文像不像好稿"，与任务成功之间隔着好几个近零因子。

**方案**（全部宿主侧、零模型调用、零费用、可回滚、旧路径保留）：
- **R1 制品即程序**：每轮产出附带类型化步骤 `{前置条件, 动作, 期望观测, 检查命令}`；宿主执行检查，通过才允许进入下一步；散文降级为说明。
- **R2 主动查询**：检查失败时系统自选下一个检查（期望信息增益最大者），不等分数。
- **R3 签名档案**：每条新增规则/事实/疫苗记录逐项符号效果 + 留出门；不通过的进拒绝缓冲、可退役。
- **R4 回滚是一等公民**：每轮前对"制品 + 宿主状态"打检查点，可回到上一个通过检查的状态再走另一条路。

**可证伪预测（先写下）**：若 R1/R4 落地，涨幅应集中在 **flaky**（当前近零因子，失败模式正是等待/重试/证据缺失）；**wrong-model（9.0）与 eacces（8.5）几乎不该变**。若那两格反而涨 >1 分，说明因子分解有误——回去重做归因，不要庆祝。

坑（都踩过）：
- 远程池：带 `tools` 的请求会路由到不可信后端 → 用 `--text-tools`；不可信后端丢 reasoning history；`channel-check` 只能跑 CLI，不能 `import`。
- `buildCompressCtx` 不把纯文本 `[tool: …]` 当工具结果（fixture 要用块形式）。
- 闸门改动最易踩的三处：`keep` 豁免句边界（到 `；` 必须停）、`stripExcludedFallback` 的"共享标识符"误伤（靠 `keep` + 保护句首）、三问只在 fixInPlay 时补。
- 旧稿（v4d8）过新闸门会出现重复提示（2400–3200 字）——预期行为，不是 bug。
- run4 有 79 行且**同一 variant/task/sample 可以出现两次**（obs green = 通过跑的观测），不是重复数据。
- 费用纪律的执行细节：评委票价记录走 judge-cache，按规范哈希记票池。
