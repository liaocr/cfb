## 0. 纠正范围与预注册（补全实现之前）

上一轮“R1–R4 全部实现”属实，但不能扩写为“四份理论文档中所有可落地部件都已实现”。本次按第一至第四轮逐项追踪，而不是只读第四轮的四个标签。理论后文明确降级/否决的路线不偷偷重新启用；论文的白盒/训练结果不等于插件的功能。

基线：`040359e`，700/0/1，20 套件，manifest 271；在独立 Linux 用户+网络命名空间（仅 loopback，无外部路由，代理变量移除）已复现；267 稿 N1–N7 全零。1 项跳过仍为原有宿主兄弟包探针。

本次新增可证伪预测：
- **C1**：块的读回字节保持一致；访问计数/新旧/剩余预算随真实调用变化，不伪称精确 provider token 数。失败 RAW/EXPLANATION 不能被默认 solver 读回；optimizer 的显式离线访问与求解器分权。
- **C2**：L0/L1/L2 每个交付层都携带同一完整的类型化义务核心，任意非空子集可解，混合周期/损坏/缺核心拒绝；预算不足拒绝整层，不抽取旧稿或删承重约束。稳定前缀字节不随轮次变化；缓存收益不在本轮宣称。
- **C3**：未知/陈旧/诊断角色错配不触发义务；单个动作 pass 不算兑现，必须完整验收证据；取消/作废不能执行。只有合法回执可进入下一轮的二元反馈，不加入失败故事。
- **C4**：S0 工程基座为 32 个本地场景、8 族、16:8:8；真实文件/状态/控制链与另一个观察器同判，扰动/评估器交换出现任一负项就拒绝。它仍是本次代理编写的合成场景，不冒充独立真实泛化留出。
- **C5**：本地有界编辑/候选搜索最多 8 个候选，受改动预算、三切分和拒绝缓冲控制；盲测在执行前持久预占，重建 JS 对象也不能重用；重复拒绝提议不消耗新评估；全拒绝不读盲测。
- **C6**：旧提示词/渲染/正文/chunks 不变，267 稿 N1–N7 全零；全部本地测试在只有 loopback 的网络命名空间运行，外部 API 请求不可能出站。

原 P1 不变：未来经批准的真实模型增益应集中 flaky，wrong-model 9.0 / eacces 8.5 几乎不变；任一涨 >1 分先重做因子归因。

## 2. 验证方法与实际结算

本地事实、状态和观察器都真实执行；模型接口不参与。Linux 网络命名空间只有 lo，外部路由为 0，环境代理移除；这比仅返回常数 modelCalls=0 更强。纯协议/场景/本地策略的成功率只评价工程机制，不能验证 SkillsBench 的独立人写结论或 P1。

最终全量：**746 通过 / 0 失败 / 1 原有宿主依赖跳过，23/23 套件；manifest 281 文件无漂移；267 稿 N1–N7 全零**。全部测试在仅 lo/外部路由 0 的 Linux 用户+网络命名空间执行，临时 HOME/DSH_HOME，不继承 API/代理/凭据环境。新增基础设施 8/0、上下文/义务 21/0、场景/搜索 17/0，共新增 46 项。类型声明只完成 Node 原生语法解析，未做 tsc 语义检查。

实际工程场景为 **32 个 / 8 族 / 16:8:8**：文件前置、修订新鲜性、条件等价、字面替换、源码保护、联合恢复、模型身份/指纹、命令返回码/输出预算。原始、格式扰动、观察器交换三种配置各 32/32；保守不行动基线 16/32。搜索累计执行 **336 个本地案例**，两个实现的观察器一致 **336/336**，实际本机 HTTP 请求 18 次、本地 oracle 子进程 336 次；外部模型/评委 API 0、费用 0。三个配置共 96 条效果行，不是 96 个独立任务。

有界搜索：3 个唯一候选、1 个重复提议跳过，候选上限 8；336 次执行中 test 48 次，全部在候选固定且持久预占之后。无检查策略因 regression-train 被拒；完整检查策略通过严格门并入库一条。32 个复发问题格留在宿主队列，不回灌模型失败故事。同一周期重复拒绝不重评；跨周期只有源码/环境指纹相同才复用认证拒绝记录，未给指纹时不将旧失败当永久真理。

已有成对观测：动作变化 16/32；没有模型答案，答案不变指标可判 0、unknown 32，不冒充 forced answering。旧历史回放仍为 33/33 逐字相等，历史授权/实时通过均 0；demo 真实失败恢复后第二批准分支通过，2 轮/2 修复/7 检查。

**这些数只证明本地工程机制，不是模型涨分。** 场景由本次代理编写、参考已知；两观察器共享参考，只是不同实现，不能说独立人写泛化。QAEval、forced answering、LLM 因果消融/信息率、生成期 token 约束、白盒 KV/RL/权重训练、任意代码空间演化及生产自动接管均未实施。P1（flaky 增益、wrong-model/eacces 几乎不变）仍未验证，所有模型/评委/生产实跑另批。不读 keys.env、不安装依赖。


## 3. 入口与回退

- `npm run verify:offline`：本轮最终验收的可复现入口；断网隔离失败直接停止，不偷偷联网。
- `npm run evidence:lab`：持久库的工程搜索；同源码只回放认证报告，源码变更拒绝在已消费族上重搜。当前工作区早期 CLI 报告与后续补丁版本不同，不能靠删库重用盲测；最新固定场景回归报告为 `.cfb-runtime/local-evidence/latest-regression.json`，可由自测重新生成，不宣称新的独立盲测。
- `src/evidence-context.js` / `src/evidence-intents.js`：完整独立描述、固定前缀、块读预算/权限、义务与二元反馈；`contextOptions` 默认为 null，只有宿主显式配置对象才接入。
- `src/local-evidence.js` / `src/evidence-search.js`：本地真实操作、受保护文档编辑、三切分异步调度/严格证书、拒绝缓存/复发队列；不修改旧提示词。
