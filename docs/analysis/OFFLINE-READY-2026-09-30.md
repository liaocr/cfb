# 离线优先、联网即用：架构强化预注册（2026-09-30）

## 本轮目标与边界

用户已确认本会话外部 API 网络会一直阻塞，要求把架构推进到未来接通网络后最大程度方便使用。本轮不再探测外网、不加载模型/GitHub密钥、不调用模型，不训练、不重复已消费留出、不自动接管生产工具；Git 只用于固定分支的保存/推送。

“无法测试”仅指真实供应商/模型效果。纯函数、状态恢复、真实 loopback HTTP、命令行与加密迁移均须实际断网自测。模型质量、供应商计费、独立泛化仍保留未知，不能用模拟结果替代。

## 归因

1. 上轮架构的跨进程 HMAC/CAS 是同一目录内的保护；Arena 跨轮恢复忽略了 `.cfb-runtime`，目录消失可能重新初始化预算。这是首先必须解决的真实缺口。
2. 旧入口只提供 plan/run；配置、诊断、断点、报告与迁移要操作者自行拼装。冻结输入/严格通道门虽已有，不能据此宣称一键可上线。
3. API返回是外部不可信数据：还需要响应字节限额、工具参数结构、秘钥回显保护、错误归类与完整配对去重；默认保留旧模型稿而非调文字。
4. 当前工程测试只零散模拟请求，需要贯穿生产编译→冻结→渠道探针→矩阵→预算→中断/恢复→归因报告的一条真实本机 HTTP 演练。

## 固定实施范围

A. **双平面持久化**：私有 HMAC 仓保留完整输入/响应；非敏感单调收据保留批准 scope、仓身份、计划摘要、预占计数/费用及 head 修订。收据存在而仓缺失/回滚/换路径或私钥则拒绝初始化。写仓与收据任何不一致停止，不猜测完成、不退款/重发。

B. **完整生命周期**：统一 prepare / doctor / simulate / run / report / export / import。配置只引用环境变量名，不接收明文钥匙；prepare/doctor/report/迁移不调用模型；run 必须显式 live，仍沿用 USD2 / 13 请求 / 0 评委 / 0 自动重试批准。

C. **安全可移植检查点**：用 Node 内置 scrypt + AES-256-GCM 加密计划/私有仓（包括 HMAC authority）及公开收据；口令只能来自指定环境变量。文件遍历、符号链接、越界/篡改、错误口令、旧 watermark、覆盖非空目标均拒绝。不能凭移植“恢复”为新预算。

D. **离线端到端**：真实 loopback 替身运行同一预算/通道/矩阵路径，至少覆盖正常13请求、错误型号/指纹/历史不可见、HTTP错误、截断、usage缺失、取消、状态丢失与迁移。模拟结果明确不是LLM得分或真实修复。

## 实现前的可证伪验收

- 新工具默认网络0；仅明确 live 进入旧批准的有界网络调用。演练只准 lo/无外路由，供应商凭据不继承。
- 有公开预占收据时删掉私有仓/回滚旧 checkpoint →下一 fetch 必须0；不得通过新目录/新价格/新模型恢复额度。
- 已认证成功响应可离线重新报告/迁移，恢复继续只发送未调用的已冻 job；未知/pending/失败仍立即停止，不重发不补样本。
- full matrix 仍1探针+12主请求；两格可见消息/工具一致，只换完整 reasoning；结果只用完整唯一配对，不拿单边/重复行算收益。
- 当前源码/协议/输入漂移、不安全 endpoint、不可用报价/密钥、样本结构错 →收费前拒绝。认证指纹/canary不是密码学型号证明。
- 原编译稿/chunks/提示词/执行权限不改；267稿N1–N7全零、旧编译33/33一致。新框架通过才启用，旧入口兼容，不保证任何未见任务绝不变差。
- 公共收据不是 OS 沙箱/远程不可回滚账本；操作者仍需保存最新收据/加密备份，并设置供应商账户额度。

## 实测

第一阶段：38项新自测；专项82/0（4套件）；真断网全量841/0/1、28套件、18.6秒；manifest308文件，无漂移/新增/缺失；267稿N1–N7全零、旧编译33/33逐字一致。默认插件/提示词/正文/chunks与执行权限不变。

真实本机HTTP演练：先完成5请求→加密导出→删除仅演练自己的私有树（公开收据保留）→0请求拒绝重置→导入→余下8请求，累计13；12个主响应完整配对，再次执行全缓存新增0。9类故障（错误型号、null指纹、历史不可见、503、截断、缺usage、工具JSON损坏、超大正文、取消）全部关闭，续跑新增0。约367KB加密检查点仅测试制品，未提交。

模型/外部API/评委0、费用0；演练返回的shell从未执行，不能说明LLM理解/修复成功/泛化。当前适配器仍限定chat-completions历史reasoning协议，不伪装其他provider具备此能力。第一阶段可手动export/import；第二阶段再补可选逐步自动加密检查点和使用文档。


## 第二阶段与最终交付

- 新增可选 `run --live --checkpoint FILE`：初始化与每次pending/accepted提交后，同步原子更新加密包。请求前的仓/水位/备份任一失败均不发；状态hook不允许Promise；回复已认证后备份失败保留真实缓存，不改成provider失败。包的独占锁/前后水位核对拒绝并发覆盖新包，遗留锁不自动抢。
- 未定价计划也能离线report/加密搬迁；内部结构验收允许明确unpriced，费用仍null，不能转成零价或创建预算。只有默认严格定价审计才能初始化有界网络执行器。
- 提供公开profile模板、统一脚本、完整最短启用/搬机/错误手册；legacy --plan/--run兼容别名不复制执行代码。默认live入口未启用，模型/GitHub钥匙未读取或保存。2个sample先后反转、冻结本地规则、响应字节/工具/敏感材料门均贯穿同一路径。

最终新增 **43 自测**；专项 **87/0/0，4套件**；真断网全量 **846通过 / 0失败 / 1原有宿主依赖跳过，28/28套件，18.6秒**。manifest **309 文件** 无漂移/新增/缺失；267稿 **N1–N7全零**，旧编译 **33/33** 逐字一致。新增4个自动备份/未价迁移反例与1个备份锁反例（相对第一阶段38项）。

独立CLI冷启动验收已执行：prepare成功、doctor预期blocked、未价report成功、无live/缺前置的live均拒绝，预算仓/真实公开收据均未创建，外部API0。两阶段都未重跑旧18任务四臂、39 episode工程回归或已消费留出；未训练、入库、批量重判、生产接管。所有本机shell回复只被分析，从未执行。
